# Naevu

## Обзор
Naevu — планета во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: планета
- Код: naevu
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: скрытность и маскировка.
- Риск/ограничение: зависит от доверия экипажа.
- Ключевая метрика/признак: время выхода в режим.
