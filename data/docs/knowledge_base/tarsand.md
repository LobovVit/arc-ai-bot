# Tarsand

## Обзор
Tarsand — планета во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: планета
- Код: tarsand
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: высокая автономность.
- Риск/ограничение: нуждается в редком ресурсе.
- Ключевая метрика/признак: Slip-индекс.

## Связи и зависимости
- См. также: Synth Flux
- См. также: Slipstream
