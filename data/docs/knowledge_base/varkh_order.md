# Varkh Order

## Обзор
Varkh Order — организация во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: организация
- Код: varkh_order
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: жёсткая иерархия.
- Риск/ограничение: опасно при неправильной настройке.
- Ключевая метрика/признак: тепловой профиль.
