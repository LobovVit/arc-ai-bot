# Slipdrive

## Обзор
Slipdrive — технология во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: технология
- Код: slipdrive
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: ориентация на скорость.
- Риск/ограничение: зависит от доверия экипажа.
- Ключевая метрика/признак: Flux-коэффициент.
