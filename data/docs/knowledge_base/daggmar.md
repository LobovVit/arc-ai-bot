# Daggmar

## Обзор
Daggmar — планета во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: планета
- Код: daggmar
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: ориентация на скорость.
- Риск/ограничение: чувствительно к помехам.
- Ключевая метрика/признак: Flux-коэффициент.
