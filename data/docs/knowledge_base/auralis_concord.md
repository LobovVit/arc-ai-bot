# Auralis Concord

## Обзор
Auralis Concord — организация во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: организация
- Код: auralis_concord
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: скрытность и маскировка.
- Риск/ограничение: требует калибровки.
- Ключевая метрика/признак: Slip-индекс.
