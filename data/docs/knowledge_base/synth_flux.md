# Synth Flux

## Обзор
Synth Flux — феномен во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: феномен
- Код: synth_flux
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: этический кодекс.
- Риск/ограничение: требует калибровки.
- Ключевая метрика/признак: Flux-коэффициент.

## Связи и зависимости
- Используют: Auralis Concord
- Искажают: Varkh Order
- Требует дисциплины и фокуса
