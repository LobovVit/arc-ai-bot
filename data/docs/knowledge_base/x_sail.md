# X-sail

## Обзор
X-sail — техника во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: техника
- Код: x_sail
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: ориентация на скорость.
- Риск/ограничение: требует калибровки.
- Ключевая метрика/признак: Slip-индекс.

- См. также: Slipstream
