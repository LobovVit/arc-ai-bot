# Vapor Citadel

## Обзор
Vapor Citadel — локация во вселенной **Asterion Saga**. Документ предназначен для внутренней базы знаний и используется в RAG-поиске.

## Ключевые факты
- Тип: локация
- Код: vapor_citadel
- Статус: канонический элемент вселенной Asterion Saga
- Ключевая особенность: ориентация на скорость.
- Риск/ограничение: требует калибровки.
- Ключевая метрика/признак: Slip-индекс.
