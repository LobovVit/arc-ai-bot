# Task 2 — Пояснение

## Какая вселенная
Синтетическая вселенная **Asterion Saga**, вдохновлённая известной космо-оперой, но с заменой ключевых терминов.

## Как заменяли термины
- Словарь замен: `data/docs/terms_map.json` (исходный термин → вымышленный).
- Скрипт: `tools/replace_terms.py` — заменяет термины в исходных текстах и сохраняет итоговую базу в `data/docs/knowledge_base/`.
- В этом пакете уже лежит готовая база: `data/docs/knowledge_base/` (35+ документов).

## Как доказать, что модель не «угадывает»
Задавайте вопросы с уникальными терминами: **Synth Flux**, **Void Core**, **Crysalis Prime**, **Directive 66** и т.п.
Без этих документов модель не сможет отвечать корректно — проверяется RAG.
